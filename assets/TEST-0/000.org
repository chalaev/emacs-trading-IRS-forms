- "USD" column is the dollar trade amount.
- Columns' order is arbitrary.
- "date" column is the trade date; trades occurred within the same day are considered indistinguishable, and their rows can be merged.
- Every sell row is expected to meet ("marry") one or more buy rows and vice versa
- In this test file, only compulsory columns are shown other recognized column names are: "fee", "spent".
- The code tries to assign any empty "acquired" values in the sell form.
